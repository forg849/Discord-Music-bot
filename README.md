# Discord Music Bot

A simple music bot for Discord, written in Python.

### Features
- YouTube music playback
- Song queue
- Skip, pause and resume
- Volume control
- Song repeat
- Stop and leave commands

### Requirements
- Python
- discord.py
- yt-dlp
- FFmpeg

### Setup
```bash
pip install discord.py yt-dlp PyNaCl
```

Set your `DISCORD_TOKEN` environment variable and run:

```bash
python main.py
```
